Agent_Coco is an autonomous documentation agent that explores a codebase, reads relevant files, and generates structured project documentation with minimal manual effort.

<!--more-->

The project follows an explicit `EXPLORE -> READ -> WRITE` workflow to inspect project structure, selectively read source files, and generate a grounded `README.md` for the repository. It uses a large language model with secure file-access controls and lightweight observability to keep the process reliable and explainable.
