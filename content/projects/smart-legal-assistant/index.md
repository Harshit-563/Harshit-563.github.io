=======
An NLP-powered contract analysis system that extracts key clauses, detects risky terms, and generates concise summaries to streamline legal review workflows.

<!--more-->

Smart Legal Assistant is an end-to-end NLP application designed to automate contract analysis and reduce manual legal review effort. The system performs clause extraction, risk detection, and abstractive summarization using modern NLP techniques and transformer-based models. Built with FastAPI for a lightweight and scalable backend, the application supports real-time processing and can be deployed using Docker for portability across environments. By combining structured information extraction with risk highlighting, the system improves efficiency and decision-making in legal document review.
