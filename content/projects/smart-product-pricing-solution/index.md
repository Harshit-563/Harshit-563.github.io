A pricing prediction system for estimating optimal product prices using historical sales data, feature engineering, and gradient-boosted models.

<!--more-->

This project treats pricing as a supervised regression task and evaluates multiple baselines before selecting boosting models for improved performance. The workflow includes data cleaning, exploratory analysis, feature transformation, and model validation, with a focus on practical decision support for marketplace pricing.
