AI Code Investigator is a repository-level RAG system for asking grounded questions about a codebase and retrieving evidence from relevant source files.

<!--more-->

The project combines repository parsing, code chunking, embedding-based retrieval, BM25 keyword matching, and reranking to surface the most relevant context before generating an answer. It is designed to help developers investigate projects faster by grounding responses in retrieved code and documentation rather than relying on unverified model output.
