## 💻 Run Locally

You can run the portfolio locally to explore its structure or make changes.

### Prerequisites

- [Git](https://git-scm.com/)
- [Hugo](https://gohugo.io/)

Check that the required tools are installed:

```bash
git --version
hugo version
```

### 1. Clone the Repository

```bash
git clone https://github.com/Harshit-563/Harshit-563.github.io.git
cd Harshit-563.github.io
```

### 2. Start the Development Server

For a standard Hugo project, run:

```bash
hugo server
```

Open the local address displayed in your terminal to preview the website.

**Note:** If the repository uses Hugo modules, Git submodules, or additional dependencies, install those requirements according to the project's configuration before starting the server.

### 3. Build the Website

Generate the static website files with:

```bash
hugo
```

Hugo typically writes the generated output to the `public/` directory unless the configuration specifies another destination.

## 📁 Project Structure
